# Produit Academy - Main Marketing Website

This repository contains the primary landing page and marketing website for Produit Academy, focusing on premium 1:1 live tuition.

## Features
- **Marketing Landing Page**: Highlighting Produit Academy's mission, vision, and core offerings.
- **Animations & Aesthetics**: High-end, professional UI with modern typography (Times New Roman for headings) and Framer Motion animations.
- **Course Navigation**: Information regarding 6th-12th grade online tuition.

## Tech Stack
- Next.js
- React
- Framer Motion
- Lucide React

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
